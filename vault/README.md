# 结构设计案例库（Obsidian Vault）

产品与机械结构设计案例库：外壳、卡扣、连接件、转轴铰链、机构、防水密封、拆解结构。首版 2026-11-13，含 15 个已核实案例；第 1 次收集后共 28 个；第 2 次 +22，共 50 个；第 3 次 +20，共 70 个；第 4 次（2026-11-17）+20，共 90 个。每 2 天新增 20 个以上，每篇做深。

## 导入 Obsidian
1. 解压 `structure-case-library.zip`，得到 `vault` 文件夹（可改名）。
2. 打开 Obsidian →「打开本地仓库 / Open folder as vault」→ 选这个文件夹。
3. 首次打开时点「信任作者并启用插件」（只有安装了社区插件才需要）。
4. 从 **首页.md** 开始浏览；可视化地图在 **案例地图.canvas**。
   - 建议在「设置 → 文件与链接」把「附件默认存放路径」设为 `附件`。
   - 可以用社区插件 Homepage 把 `首页.md` 设为启动页（可选）。

## 推荐插件
| 插件 | 用途 | 必需？ |
| --- | --- | --- |
| **Dataview**（社区） | 首页与分类索引页里的动态表格、统计、卡片视图；设置里打开「Enable JavaScript Queries」才能显示卡片视图 | 推荐（没有也能看静态备用表） |
| Canvas（核心，默认开启） | 打开 `案例地图.canvas` | 是 |
| Properties / 属性视图（核心） | 查看、编辑每篇案例顶部的属性 | 默认开启 |
| Mermaid（内置） | 分类图、剖面示意图 | 内置无需安装 |
| Templater / 核心「模板」 | 用 `00-说明/案例模板.md` 新建案例（模板文件夹设为 `00-说明`） | 可选 |
| Image Toolkit / Image Captions | 放大看拆解图 | 可选 |

## 目录
```

00-说明/收集日志.md      每次收集记录 + 待跟进线索
01-… ~ 07-…/             各一级分类文件夹，每个都有「索引」页
附件/                    配图（版权归原作者，仅供个人学习）
```
