# 电磁门锁（磁力锁）：通电线圈吸合衔铁，断电释放

> [!summary] 一句话概述
> 门禁磁力锁用通电线圈把锁体做成电磁铁，吸住门扇上的金属衔铁来锁门；一旦断电，吸力消失，门就可以推开。这和橱柜永磁门吸不同：门吸不需供电、也不能远程释放；也和本批电永磁吸盘不同：电永磁只在充磁/退磁的瞬间用电，停电后仍保持夹紧，而典型磁力锁停电就开（Fail-Safe）。

### 装配顺序

按 Securitron 安装说明书的逻辑（先做现场勘察再钻孔）：

1. 确认门框和安装面的强度不低于所选锁的保持力，并规划走线，防止被破坏。
2. 用随机模板在门框和门扇上定位钻孔。垂直或偏置安装时，说明书对衔铁孔相对折线的偏移有专门毫米值（如垂直安装把衔铁孔再移远 1/10" / 2.5 mm 等），须按对应图施工，不要混用。
3. 把锁体固定到门框，把衔铁用 Sex Bolt、滚销和橡胶垫圈装到门扇，保证闭合时锁面与衔铁贴合。
4. 按 12 VDC 或 24 VDC 接线。说明书写明双电压 12/24 VDC，并警告不可用半波整流或交流供电。按电流表和导线截面表选择线径，保证锁端电压足够。
5. 通电检查吸合；维护时按说明书周期清洁锁面。保持力下降时先查电压、电流和衔铁安装。

> 瓯宝选型文补充：非金属门要加金属安装板；消防通道选 Fail-Safe。逐步钻孔尺寸以随机模板为准。

### 受力与运动分析

- **受力路径**：推门或撬门的力经门扇传到衔铁，再经贴合面的磁拉力传到锁体和门框。Securitron 给出的保持力是这套路径的额定值：M32 600 lbs / 272 kg，M62 1200 lbs / 544 kg，M82 1800 lbs / 816 kg。电流（规格表）：12 VDC 时 300 / 250 / 350 mA，24 VDC 时 150 / 150 / 200 mA。电压不足或锁面不洁，保持力下降。
- **运动关系**：锁定时锁体与衔铁之间无工作间隙运动，靠磁力保持。解锁是切断线圈电流。门扇开合是绕铰链的转动，衔铁必须能准确回到锁面。
- **失效风险**：停电或线路被切断时，典型电磁锁释放——这是消防通道需要的 Fail-Safe，也是非法切断电源时的风险，高安全区要另外做管理（门禁、备份电源等）。瓯宝另提到「断电闭锁 Fail-Secure」用于机房等，但未在已打开正文里给出这类锁如何在断电后仍靠电磁吸合保持；典型电磁锁停电即无磁场，不能把 Fail-Secure 理解成「同一块只靠线圈的磁力锁断电还吸住」。气隙、油漆、灰尘会显著降低吸力（Securitron 清洁与故障检查）。安装面强度不够，锁还没达到额定保持力，门框先坏。

## 优缺点

**优点**
- 锁合面是平面吸合，没有锁舌插入的对位苛刻要求，适合频繁通行的通道门。
- Fail-Safe 型号在火灾断电时自动开门，符合疏散逻辑。
- 没有锁舌机械磨损，瓯宝把它写成静音、长寿命的理由之一。
- 可以加磁场或门磁监测，把「是否真正吸合」告诉门禁系统。

**缺点 / 代价**
- 必须持续供电才能锁门，停电就开，不适合把「断电仍要锁死」寄托在同一块纯电磁锁上。
- 保持力对气隙和表面污染非常敏感，安装和清洁比普通碰锁更关键。
- 功耗按电流持续存在，电源和线径要按锁端电压设计，不能只按控制器输出空载电压选型。
- 破坏者切断电源或把衔铁撬出气隙，锁就会失效，需要配合门框强度和防拆走线。

## 可借鉴点

- 先写清停电策略：要疏散就用通电锁、断电开的 Fail-Safe；要断电仍锁死，不能指望同一只电磁铁，应改机械锁或电永磁等另一类结构。
- 衔铁不要做成完全刚性死连接，留一点浮动（垫圈、长圆孔或弹性件）让门关到位时锁面能贴平。
- 规格书同时给保持力和两种电压下的电流，便于算电源和压降。
- 把「锁面清洁、电压到位、衔铁安装」写成保持力下降的标准检查单。
- 对照橱柜门吸：永磁门吸不耗电，但也无法电控释放；对照电永磁吸盘：夹具可以停电保持，门禁通道通常不能直接套用。
